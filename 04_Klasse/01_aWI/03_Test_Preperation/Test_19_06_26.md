## Observer Pattern – UML Diagram

### **Scenario:**

You are developing a **weather monitoring system** for a smart home application. The system has a **WeatherStation** that continuously measures temperature, humidity, and air pressure. 

Multiple display devices need to be updated automatically whenever the weather data changes:
- A **CurrentConditionsDisplay** shows the current temperature and humidity
- A **ForecastDisplay** predicts weather trends based on pressure changes
- A **StatisticsDisplay** shows average, min, and max temperatures

**Requirements:**
- When the WeatherStation receives new measurements, all connected displays must be notified automatically
- Displays should be able to register/unregister from the WeatherStation at runtime
- The WeatherStation should not know the specific types of displays connected

## Singleton Pattern – Code Explanation

### **Code:**

```typescript
class DatabaseConnection {
    private static instance: DatabaseConnection;
    private connectionString: string;
    private isConnected: boolean;

    private constructor() {
        this.connectionString = "localhost:5432/mydb";
        this.isConnected = false;
        console.log("Database connection initialized");
    }

    public static getInstance(): DatabaseConnection {
        if (!DatabaseConnection.instance) {
            DatabaseConnection.instance = new DatabaseConnection();
        }
        return DatabaseConnection.instance;
    }

    public connect(): void {
        if (!this.isConnected) {
            this.isConnected = true;
            console.log("Connected to database");
        }
    }

    public query(sql: string): void {
        if (this.isConnected) {
            console.log(`Executing query: ${sql}`);
        }
    }
}

// Usage
const db1 = DatabaseConnection.getInstance();
const db2 = DatabaseConnection.getInstance();

console.log(db1 === db2); // What will this print?
```
